GENIESimConfig dataclass 

GENIESimConfig(placement: str = 'fixed', positions: Optional[list] = None, n_events: Optional[int] = None, random_state_seed: Optional[int] = None, interaction_filter: Optional[str] = None, direction_mode: str = 'as-is')

Bases: ConfigBase

GENIE simulation parameters configuration.

Parameters:
  • placement (str, default: 'fixed' ) –

    How to place event vertices. 'random' samples uniformly inside the detector bounding cylinder; 'fixed' uses positions.

  • positions (list, default: None ) –

    For placement='fixed': a single [x, y, z] applied to all events, or a list of [x, y, z] with one entry per event.

  • n_events (int, default: None ) –

    Number of events to simulate. When larger than the number of events in the ROOT file, events are resampled with replacement. When None, all events in the file are used exactly once.

  • random_state_seed (int, default: None ) –

    Seed for the NumPy RNG used when placement='random' or when resampling is active.

  • interaction_filter (str, default: None ) –

    If set, only GENIE events whose EvtCode description contains this substring are kept before resampling. Typical values: 'CC', 'NC'.

  • direction_mode (str, default: 'as-is' ) –

    How to orient events. 'as-is' keeps the momenta from the ROOT file; 'isotropic' applies a uniform random rotation per event to the initial state and all final states. Use 'isotropic' for atmospheric-neutrino files generated with a fixed gevgen beam direction; the rotation is exact for events on an unpolarized target.

OlympusSimConfig dataclass 

OlympusSimConfig(files: bool = True, wavelength: int = 700, splitter: int = 100000, max_distance: float = 300.0, min_distance_from_dom: float = 0.1, module_chunk: int = 128, photon_chunk: int = 2 ** 18, warm_up: bool = False, warm_up_sources: int = 2 ** 12, warm_up_pairs: int = 2 ** 18)

Bases: ConfigBase

Olympus simulation parameters configuration.

Parameters:
  • files (bool, default: True ) –

    Whether the run reads its injection from file.

  • wavelength (int, default: 700 ) –

    Reference wavelength in nm for the speed of light in the medium.

  • module_chunk (int, default: 128 ) –

    Number of modules evaluated per jitted model-input call. This is what keeps the compiled-executable cache from growing with the module count; see sources_to_model_input_chunked. Results do not depend on it. Larger values trade a bigger per-call temporary for fewer calls.

  • photon_chunk (int, default: 2 ** 18 ) –

    Most photons handed to the arrival-time flow sampler in one call. Events are never batched together; what sets device memory is the number of detected photons of the single brightest particle, and this bounds the sampler's working set at a fixed size however bright it is. Lower it on a small GPU. Results for particles that fit in one chunk do not depend on it. See sample_photon_times.

  • warm_up (bool, default: False ) –

    Experimental, off by default. Compile every kernel bucket at start-up instead of when the first particle needing it arrives. Makes the per-event time flat from the first event and fails fast on a device that cannot hold the largest kernel. Does not change results. Needs more testing before it becomes the standard.

  • warm_up_sources (int, default: 2 ** 12 ) –

    Top of the source bucket ladder compiled by warm_up.

  • warm_up_pairs (int, default: 2 ** 18 ) –

    Top of the source-module pair bucket ladders compiled by warm_up.

  • max_distance (float, default: 300.0 ) –

    Maximum source-to-module distance in metres. Pairs beyond it cannot contribute hits and are dropped before propagation. Changing it changes physics, not just memory.

  • min_distance_from_dom (float, default: 0.1 ) –

    Minimum source-to-module distance in metres, below which the optical model is not evaluated.

  • splitter (int, default: 100000 ) –

    Unused. Retained so that existing configuration files continue to load; the module axis is now walked in module_chunk-sized pieces inside the propagator instead of being split here.

def from_toml(self, toml_file: str) -> None:
    """Load a TOML file and apply it over the current defaults in-place.

    Parameters
    ----------
    toml_file : str
        Path to a TOML file to load.
    """
    import tomllib

    with open(toml_file, "rb") as fh:
        data = tomllib.load(fh)
    if data:
        _deep_apply(self, data)

RunConfig dataclass 

RunConfig(run_number: int = 1337, nevents: int = 10, verbosity: str = 'WARNING', logfile: Optional[str] = None, log_format: Optional[str] = None, storage_prefix: str = './output/', outfile: Optional[str] = None, random_state_seed: Optional[int] = None, summary_mode: str = 'user', banner: bool = False, compact: bool = False, summary_json: bool = False, summary_json_path: Optional[str] = None, progress_threshold: int = 10, jax_release_interval: int = 0)

Bases: ConfigBase

Run-related configuration.

Parameters:
  • run_number (int, default: 1337 ) –

    Unique run identifier.

  • nevents (int, default: 10 ) –

    Number of events to simulate (must be > 0).

  • verbosity (str or int, default: 'WARNING' ) –

    Logging verbosity. Allowed string values: 'DEBUG', 'INFO', 'WARNING', 'ERROR', 'CRITICAL' (case-insensitive) or a numeric logging level.

  • logfile (str, default: None ) –

    Path to a file to write logs. If None, logs go to console.

  • log_format (str, default: None ) –

    Logging format string for handlers.

  • storage_prefix (str, default: './output/' ) –

    Base directory for output files.

  • outfile (str, default: None ) –

    Explicit output file path (parquet). If None, a path under storage_prefix will be used.

  • random_state_seed (int, default: None ) –

    Seed for RNGs used in injection/propagation.

  • summary_mode (str, default: 'user' ) –

    Reporting mode. Allowed values: 'user' (default) and 'debug'. 'user' prints a user-friendly, compact summary to the console and collapses noisy third-party output. 'debug' prints a developer-oriented summary at DEBUG level with verbose logging of captured warnings and native prints.

  • banner (bool, default: False ) –

    Show ASCII banner from assets when True.

  • compact (bool, default: False ) –

    Emit a compact single-line summary for batch runs when True.

  • summary_json (bool, default: False ) –

    If True, write a machine-readable JSON summary alongside the output file.

  • summary_json_path (str, default: None ) –

    Explicit path for JSON summary (overrides default outfile + '.summary.json').

  • progress_threshold (int, default: 10 ) –

    Minimum number of events required to display progress bars (tqdm).

  • jax_release_interval (int, default: 0 ) –

    Drop the JAX compiled-executable cache every this many photon propagations; 0 disables the release. The cache grows to several GB per process on a large detector and never shrinks on its own, so on a long run it, not the event data, is what exhausts memory. Releasing trades wall time for that memory, so enable it when memory is the binding constraint and pair it with the persistent on-disk compilation cache (jax_compilation_cache_dir), which turns most of the re-compilation into a cache read.
Notes

To enable the debug summary when running examples that do not expose CLI flags, set::

from prometheus import config
config.run.summary_mode = 'debug'
config.run.verbosity = 'DEBUG'  # optional: enable logger DEBUG-level output

The verbosity parameter accepts either standard logging level names or integers (see Python's logging module).
